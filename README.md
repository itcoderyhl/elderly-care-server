# elderly-care-server
基于SpringBoot3+Vue3前后端分离的养老服务平台系统（源码+文档），系统包含管理员、护工、用户角色，功能如下： 管理员：首页统计（数据统计、床位统计、老人性别统计、过去7天入住人数统计）；护工管理；床位管理（房间管理、床位管理）；入住登记；访客记录；外出报备；缴费管理；新闻管理；系统留言；公告管理；入院指南；修改个人资料；修改密码。 护工：床位管理（房间查看、床位查看）；入住登记；访客记录；外出报备；缴费管理；公告查看；修改个人资料；修改密码。 用户：注册、登录；入院指南；养老资讯（详情、点赞、评论）；系统留言；通知公告。用户还具有个人中心功能，包括：新闻点赞、新闻评论、入住管理、外出报备、访客记录、缴费账单、系统留言、个人资料、修改密码。
